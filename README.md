# KPI Central — الموقع التعريفي

موقع ثابت يُنشر من فرع `main` عبر GitHub Pages على النطاق `kpi-central.com`.

## الملفات
- `index.html`: الصفحة الرئيسية، وفيها نموذج التواصل.
- `subscribe/index.html`: نموذج الاشتراك.
- `login.html`: تحويل إلى صفحة دخول العملاء في لوحة المؤشرات.
- `assets/`: الصور والشعار والأنماط.
- `CNAME`: النطاق المخصص لـ GitHub Pages.

## الربط بالأنظمة
- نموذج الاشتراك ونموذج التواصل يرسلان إلى تطبيق Google Apps Script «KPI Central Platform Automation».
- زر «دخول العملاء» ومسار `/login` يفتحان صفحة الدخول في لوحة المؤشرات (Apps Script).
- لا يحتوي الموقع أي كلمات مرور أو مفاتيح أو بيانات عملاء.
